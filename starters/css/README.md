# CSS nativo · tokens + capas + Vite + Biome

Sin Tailwind ni Sass. HTML + CSS, con prueba de estructura mediante `node:test` y build estático con Vite.

```sh
pnpm install
pnpm lint
pnpm test
pnpm build
pnpm dev
```

La prueba estructural no sustituye pruebas visuales de navegador. Versionar `pnpm-lock.yaml` tras la instalación inicial.

Control integrado: `pnpm run check`.
