# Contrato de trabajo del template `playwright`

- Cambia solo lo imprescindible para cumplir el requisito.
- Mantén los tests deterministas, pequeños y sin servicios externos.
- Antes de terminar, ejecuta los gates definidos en `starter.json` que estén disponibles.
- Nunca declares PASS de un gate que no pudiste ejecutar.
- No introduzcas credenciales, datos clínicos, telemetría ni dependencias innecesarias.
- Actualiza y versiona el lockfile después de instalar dependencias cuando corresponda.
